## 🚀 How to Run Locally

### Option 1: Double-click `start.bat` (Windows)
Double-click `start.bat` in this folder. It starts the local HTTP server and opens `http://localhost:3000` automatically in your browser.

### Option 2: Python HTTP Server
```bash
python -m http.server 3000
```
Open `http://localhost:3000` in your web browser.

### Option 3: Node.js / NPM
```bash
npm start
```
